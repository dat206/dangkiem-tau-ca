## 1. Số #003: Thiết lập Nền tảng Frontend 

### Công nghệ sử dụng
- **Framework:** React 19 + Vite 8 (Tối ưu tốc độ build và hot reload).
- **Styling:** Tailwind CSS v4 (Sử dụng kiến trúc Engine mới, CSS-first).
- **API Client:** Axios (Cấu hình sẵn Instance và Interceptor).
- **Components:** Shadcn/ui & Lucid Icons (Giao diện hiện đại).

### Kết quả triển khai
- [x] **Cấu trúc thư mục chuẩn:** 
  - `src/components/`: Lưu trữ các thành phần UI dùng chung.
  - `src/api/`: Quản lý các hàm gọi API tập trung.
  - `src/hooks/`: Chứa các logic React hooks tùy chỉnh.
- [x] **Cấu hình Proxy:** Đã thiết lập trong `vite.config.js` để kết nối thông suốt với Backend (localhost:8000).
- [x] **Tối ưu hóa Giao diện (UX Focus):**
  - **Lược bỏ thông tin kỹ thuật:** Đã gỡ bỏ toàn bộ các đề cập đến React, Vite, PostgreSQL trên UI để tập trung vào nghiệp vụ.
  - **Quy trình hóa:** Thiết lập luồng 3 bước (Cấu hình -> Tải lên -> Kết quả) giúp người dùng dễ dàng thao tác.
  - **Clean Boilerplate:** Dọn dẹp mã nguồn mặc định, tối ưu hóa tốc độ tải trang.

## 2. Số #015: Component Cấu hình báo cáo

### Tính năng
- [x] **Giao diện:** Glassmorphism, đổ bóng mờ, bo góc lớn.
- [x] **Logic thông minh:** 
  - Tự động lấy **Năm hiện tại** làm mặc định.
  - Dropdown chọn Quý (I, II, III, IV) trình bày trực quan.
- [x] **Quản lý Tỉnh thành:**
  - Phân nhóm tỉnh theo **Miền Bắc** và **Miền Trung**.
  - Tích hợp ô **Tìm kiếm tỉnh** thời gian thực (Search-as-you-type).
  - Nút **"Tất cả"** và **"Bỏ hết"** tối ưu hóa thao tác người dùng.
- [x] **Ghi nhớ trạng thái:** Tự động lưu tỉnh đã chọn vào `localStorage`. Khi load lại trang, cấu hình vẫn được giữ nguyên.
- [x] **Validation:** Thông báo lỗi sinh động bằng Toast và Animation khi người dùng chưa chọn tỉnh.

## 4. Hướng dẫn Kiểm tra
1. Truy cập thư mục `frontend/`.
2. Chạy lệnh: `npm run dev`.
3. Mở trình duyệt tại: `http://localhost:5173`.
4. **Thao tác thử:** 
   - Thay đổi Năm và Quý.
   - Gõ "Quảng" vào ô tìm kiếm để lọc tỉnh.
   - Bấm "Tất cả" -> Bấm "Xác nhận" -> Xem thông báo thành công.
   - F5 lại trang để thấy dữ liệu tỉnh vẫn được lưu.
